## 未確認・食い違い

確認できない数字は表の確定欄に書いていません。

- **11/14 の 429 と 427。** ダッシュボードの配信欄は、11/14 04:30 と 13:21 の両方でフォロワー 429。ダッシュボードの現在値と、19:16 の公式公開APIは 427。自作記録の11/14昼は開始 430・終了 429。差の理由は未確認です。11/14朝の 429（+7）は配信欄だけで、自作の開始・終了スナップショットがありません。
- **曲の回数は出典で一致しません。** 例: 完璧主義で☆ は過去1ヶ月7回 / 自作記録2回。とくべチュ、して は7回 / 1回。期間も集め方も違うので、混ぜません。
- **自作記録のない日:** 11/1・11/2・11/9（および 11/8夕〜11/9 の一部）。数字を0にも、前後から補うこともしません。
- **SHOWランクとまいにち日数の日付ごとの推移** は、今回の出典では 11/14 現在値しか確認できていません。
- **同一日内のフォロワーの前後。** 例: 11/13夜①の終了 423、夜②の開始・終了 422。11/11夕方は開始 415・終了 414 で、変動の確定は未確認です。
- **Draft の数字ページ**（#620、#628 など）は、出典としては使えますが、本番サイトに載っているとは限りません。

## 担当と更新ルール

- **集計:** 公開ページと自作記録から数字を集め、出典URLまたはファイル名を付ける。確認できない値は空欄のまま「未確認」へ。
- **レビュー・追記:** むぎが内容を見て、抜けや表現を直す。
- **週次:** 日曜 20:00（Asia/Tokyo、前後15分）のルーチンで、その週の分を足す。データが取れない週は「今週は見送り」とし、数字を埋めません。
- **公開の境界:** 私的な関係、個人情報、制作者の職業、視聴者の個人名は書きません。本人の顔の生成・加工はしません。投稿・merge・共有設定の変更は、別の明示的な判断があるときだけです。
- **既存の各回レポート**（`data-lab/reports/`）と、この横断まとめを同じファイルで上書きしない。衝突しやすい `data-lab/index.html` や `vite.config.ts` は、このDraftでは触っていません。

## 使い方の注意

- フォロワーの「日付ごと」は自作記録のその日の最後の値です。ダッシュボードの配信行のフォロワー（その枠の時点）とは定義が違います。
- 配信時間は開始〜終了検知の差で、公式の枠尺そのものではないことがあります。
- イベントptの推定換算や、画面カウンターの途中参考値は、この表の確定欄には入れていません。各回の MILY SIGNAL レポート側を見てください。
