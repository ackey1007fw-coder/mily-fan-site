# 配信NG時間の掲示（2026-09-26確認）

## 出典と対象

オーナー提供のSHOWROOM配信画面で、本人が掲示した「配信NG時間」を目視確認。受領・確認日は2026-09-26。掲示の正確な時刻と恒久permalinkは未確認。
掲示は26日（土）〜2日（金）。依頼時の対象週として2026-09-26〜2026-10-02に対応させた。読み取った時刻の正本は `src/data/streamBlackouts.ts`。

## 公開内容

- HOMEは当日分のコンパクトな案内と `/support/#stream-ng` への導線。
- Supportは7日分のNG時間と、その補集合である「NG時間外（配信未定）」を表示。
- 10/1はNGが2区間。14:00〜16:30の中抜けを失わない。
- 0:00〜24:00からNG区間を除く計算だけであり、配信可能性や開始時刻の予測ではない。
- NG時間外を `StreamSlot` やカレンダーイベントに変換しない。API取得の確定予定をNG表で取り消さない。
- 掲示は配信の制約であり、ラジオ番組の放送休止や本人の出演予定とは判断しない。
- JSTで期間終了後はHOMEの案内を非表示、Supportで終了済みの記録として折りたたむ。対象期間外の予定は推測しない。

## 素材・作業境界

提供画面には第三者の表示名・順位が含まれるため、画像そのものは掲載せず時刻表のみ掲載。顔画像の生成・加工、別回素材の流用はしない。
NEWS・配信レポート・streamScheduleの既存open PRと編集先を分離するため、これらと共通のCONTENT-OPS台帳には触らず、本記録を残す。他サイト・SNS・通知・録画設定は変更しない。

## 検証

全7日の転記と補集合、複数NG区間、境界、入力不正、対象期間外の扱い、確定予定との分離を専用テストで検証する。
既存CIのブラウザー検証に相乗りし、PC・390px・320px・WebKitで案内と移動、横はみ出し、期限切れの表示を確認する。実行結果はPRに記録する。
