# 『みんなの太陽』MV AI制作室

このディレクトリは、三橋莉子（みりぃ）さんの非公式応援MV『みんなの太陽』を、ChatGPT / Claude / Grok と共同制作するための共有ワークスペースです。

## 目的

オーナーがAI間の「伝書鳩」にならず、各AIが同じ一次情報・決定事項・最新の制作状況を直接読んでから提案・制作できるようにする。

この制作室では、**GitHubのDraft PR Conversationを会議室**、このディレクトリのMarkdownを**共有の黒板 / source of truth**として使います。

## 最初に読む順番

どのAIも作業開始時に必ず次を確認してください。

1. リポジトリ直下 `AGENTS.md`
2. この `README.md`
3. `BRIEF.md`
4. `DECISIONS.md`
5. 自分の担当ファイル
6. Draft PR Conversation の最新コメント

`AGENTS.md` がリポジトリ全体の最上位ルールです。矛盾する場合は `AGENTS.md` を優先します。

## 重要: このrepoは公開です

このリポジトリとDraft PRの内容は公開される前提で扱います。

書いてよいもの:
- 本人が公開しているプロフィール・活動情報
- オーナーが公開利用を明示承認した素材についての制作メモ
- MVの構成、演出、技術的な検討
- Suno楽曲の制作・編集上の情報

書かないもの:
- 私的DMの本文・要約
- 非公開の人間関係
- 住所、連絡先、家族情報などの私的情報
- 本人が公開していない情報
- 権利や公開可否が確認できていない素材そのもの

## 今回の固定方針

- 本人の顔・身体をAIで生成、置換、補正、変形しない。
- 本人写真をReference-to-Video等でAI動画化しない。
- 本人へのリップシンクを行わない。
- 本人素材は、公開・利用確認済みの実写写真 / 実写動画をそのまま主素材として使う。
- Grok生成は**本人が登場しない情景・象徴B-roll**に限定する。
- MVの核は「みりぃが輝く」だけではなく、**『こんきょのない じしんを だれかに わたす』**こと。
- 公開版では **「非公式応援MV」** を明記する。

## 役割分担

### ChatGPT（じぴ）— 監督 / 統合
- 全体方針と決定事項の統合
- 各AIの提案の衝突整理
- 歌詞と絵の意味、単調さ、距離感の最終レビュー
- `DECISIONS.md` の整理

### Claude — 構成 / 絵コンテ
- 秒単位の構成
- 35カット絵コンテ
- 歌詞と映像の意味対応
- 大サビまでの感情曲線
- 担当ファイル: `STORYBOARD.md`

### Grok — 情景映像
- 本人を使わないAI B-roll案
- 12本前後の情景生成プロンプト
- 生成結果の採否メモ
- 担当ファイル: `GROK_SHOTS.md`

### オーナー
- 最終決定
- 本人素材の公開利用可否
- 実編集（CapCut等）と完成版の確認

## ファイル競合を避けるルール

複数AIが同じファイルを同時編集しない。

- Claude → `STORYBOARD.md`
- Grok → `GROK_SHOTS.md`
- ChatGPT → `DECISIONS.md` と必要に応じた統合レビュー
- `BRIEF.md` の固定条件を変更したい場合は、まずDraft PRに提案コメントを残す。勝手に書き換えない。

## 会議のやり方

各AIは作業後、Draft PR Conversationへ次の形式で短く残してください。

```text
[AI名] YYYY-MM-DD HH:mm JST
担当: 
見たもの: 
提案 / 変更: 
他AIに確認したいこと: 
オーナー判断が必要: なし / あり（内容）
```

他AIは次回起動時に最新コメントを読んでから作業します。リアルタイムの自動会話ではありませんが、オーナーが回答をコピーして運ぶ必要はなくなります。

## 完成条件

- 歌詞の意味と映像が一致している
- 写真をふんだんに使いながら単調になっていない
- 1:57.0 のFinal Chorusが最大の開放点になっている
- 「自信を人へ渡す」という物語が見える
- 本人の実在映像をAIで勝手に改変していない
- 非公式応援MV表記がある
- 公開情報 / 承認済み素材だけで構成されている
