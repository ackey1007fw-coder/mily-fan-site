# 『みんなの太陽』MV AI制作室

このディレクトリは、三橋莉子（みりぃ）さんの非公式応援MV『みんなの太陽』を、ChatGPT / Claude / Grok と共同制作するための共有ワークスペースです。

## 目的

オーナーがAI間の「伝書鳩」にならず、各AIが同じ一次情報・決定事項・最新の制作状況を直接読んでから提案・制作できるようにする。

この制作室では、**GitHubのDraft PR Conversationを会議室**、このディレクトリのMarkdownを**共有の黒板 / source of truth**として使います。

## 最初に読む順番

どのAIも作業開始時に必ず次を確認してください。

1. リポジトリ直下 `AGENTS.md`
2. この `README.md`
3. `BRIEF.md`
4. `DECISIONS.md`
5. 自分の担当ファイル
6. Draft PR Conversation の最新コメント

`AGENTS.md` がリポジトリ全体の最上位ルールです。矛盾する場合は `AGENTS.md` を優先します。
MVの具体的なカット割りは、Claudeが管理する `STORYBOARD.md` の **v2.1.1実体**を正本とします。

## 重要: このrepoは公開です

このリポジトリとDraft PRの内容は公開される前提で扱います。

書いてよいもの:
- 本人が公開しているプロフィール・活動情報
- オーナーが公開利用を明示承認した素材についての制作メモ
- MVの構成、演出、技術的な検討
- Suno楽曲の制作・編集上の情報
- `S1`〜`S42` / `G1`〜`G6` など制作上の参照ID

書かないもの:
- 私的DMの本文・要約
- 非公開の人間関係
- 住所、連絡先、家族情報などの私的情報
- 本人が公開していない情報
- 権利や公開可否が確認できていない素材そのもの
- 本人写真・動画の原本ファイル
- 不要なGoogle DriveファイルIDやローカルパス

本人素材のファイル本体はGoogle Drive / ローカル等で管理し、このpublic repoには置きません。

## 今回の固定方針

- `STORYBOARD.md` v2.1.1 = **全48カット**。
- 本人写真カットは **S1〜S42の42カット**、本人なし情景B-rollは **G1〜G6の6カット**。
- Role実体は **Hero 9 / 補助 22 / モンタージュ 11**。
- 設計尺は **164.3秒**。実音源は **164.352秒**で、最終書き出し時のみ末尾を実音源へスナップする。
- 本人の顔・身体をAIで生成、置換、補正、変形しない。
- 本人写真をReference-to-Video等でAI動画化しない。
- 本人へのリップシンクを行わない。
- 本人素材は、公開・利用確認済みの実写写真 / 実写動画をそのまま主素材として使う。
- 生成AIは**本人・人物・人体が登場しない情景・象徴B-roll**に限定する。
- MVの核は「みりぃが輝く」だけではなく、**『こんきょのない じしんを だれかに わたす』**こと。
- 公開版では **「非公式応援MV」** を明記する。
- 追加課金が必要な生成処理は原則使わない。実行前に0円 / 加入プラン内を確認し、有料なら止める。

## 役割分担

### ChatGPT（じぴ）— 監督 / 統合
- 全体方針と決定事項の統合
- 各AIの提案の衝突整理
- 歌詞と絵の意味、単調さ、距離感の最終レビュー
- `DECISIONS.md` の整理
- `README.md` / `BRIEF.md` / `STATUS.md` / PR本文など共有情報の同期

### Claude — 構成 / 絵コンテ
- 秒単位の構成
- `STORYBOARD.md` v2.1.1（48カット）の管理
- 歌詞と映像の意味対応
- 大サビまでの感情曲線
- 担当ファイル: `STORYBOARD.md`

### Grok / GrokBot — 情景映像
- `STORYBOARD.md` の **G1〜G6だけ**を本人・人物・人体なしのB-rollとして具体化
- 生成プロンプトと生成結果の採否メモ
- 有料クレジットを使わない
- 担当ファイル: `GROK_SHOTS.md`

### オーナー
- 最終決定
- 本人素材の公開利用可否
- 本人写真の最終選定
- ローカル編集結果と完成版の確認

## 編集環境

CapCutは前提にしません。

- 本線: FFmpeg + Codex / Cursor / Claude Code等によるローカル編集・検算
- Canva: タイトル、クレジット、サムネイル、必要な最終調整に任意利用
- Grok Build: 必要なら素材・進捗ダッシュボード用途
- 有料生成ツール: 原則使用しない

FFmpeg編集キットや本人素材は、このpublic fan-site repoへ入れず **local / private運用**を基本とします。

## ファイル競合を避けるルール

複数AIが同じファイルを同時編集しない。

- Claude → `STORYBOARD.md`
- Grok / GrokBot → `GROK_SHOTS.md`
- ChatGPT → `DECISIONS.md` と必要に応じた共有文書の同期 / 統合レビュー
- `BRIEF.md` の固定条件を変更する場合は、Draft PR Conversationに変更内容を先に残してから同期する。

## 会議のやり方

各AIは作業後、Draft PR Conversationへ次の形式で短く残してください。

```text
[AI名] YYYY-MM-DD HH:mm JST
担当:
見たもの:
提案 / 変更:
他AIに確認したいこと:
オーナー判断が必要: なし / あり（内容）
```

他AIは次回起動時に最新コメントを読んでから作業します。リアルタイムの自動会話ではありませんが、オーナーが回答をコピーして運ぶ必要はありません。
