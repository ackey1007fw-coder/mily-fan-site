# 『みんなの太陽』MV 決定ログ

このファイルはMV制作内の確定事項だけを記録します。
リポジトリ全体の運用ルールを変更するものではありません。

原則としてChatGPT（監督 / 統合）が、Draft PRでの議論を確認してから更新します。
他AIは決定を変更したい場合、このファイルを直接上書きせずDraft PR Conversationへ提案してください。

## D-001: 本人をAI動画化しない

**Status:** Accepted

本人写真をReference-to-Video等へ入力し、髪・顔・身体・表情・動作をAIで生成して動かす方法は使わない。

理由:
- 本人が実際にしていない動作を勝手に合成しないため
- 実在人物の顔を生成・加工しないrepoルールと整合させるため
- 応援作品として本人素材を尊重するため

## D-002: Grokは本人なしB-roll担当

**Status:** Accepted

Grok等の動画生成AIは、本人が登場しない情景・象徴素材に限定する。

例:
- 朝日
- 光
- 空
- ひまわり
- ラジオを象徴する空間
- 和の情景
- ステージライト

## D-003: MVのテーマは「自信の受け渡し」

**Status:** Accepted

タイトル「みんなの太陽」の意味を、単なる本人賛美ではなく、
「こんきょのない じしんを だれかに わたせたなら」に象徴される**勇気 / 自信の受け渡し**として描く。

## D-004: 1:57.0を最大の開放点にする

**Status:** Accepted

Final Chorus開始の1:57.0を全編最大の見せ場とする。
直前約3秒は意図的に映像情報量を落とし、1:57.0で一気に開く。

## D-005: 「だれかに わたせたなら」は人物を出さない

**Status:** Accepted

約1:07.2 / 2:16.0の2箇所は、原則として本人写真を置かず象徴映像で表現する。

- 1回目: 光が生まれる / 渡したい願い
- 2回目: 光が複数へ広がる / すでに届いている

## D-006: 「非公式応援MV」を明記する

**Status:** Accepted

完成MVまたはエンドクレジットに「非公式応援MV」を明記し、公式・公認・本人制作と誤認されないようにする。

## D-007: 写真は35枚に固定しない

**Status:** Accepted

35カットは編集設計の基準であり、本人写真の使用枚数上限ではない。
写真をふんだんに使う方針とし、45〜60枚程度も許容する。

## D-008: Claude / Grok / ChatGPTの担当ファイルを分ける

**Status:** Accepted

- Claude: `STORYBOARD.md`
- Grok: `GROK_SHOTS.md`
- ChatGPT: `DECISIONS.md` と統合レビュー

同じファイルを複数AIが並行編集しない。
