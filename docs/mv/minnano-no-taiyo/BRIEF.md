## 作品の核

このMVは「みりぃが太陽のように輝いている」と褒めるだけの作品にはしない。

中心に置く歌詞は:

> こんきょのない じしんを だれかに わたせたなら

タイトル「みんなの太陽」を、**自分の明るさや勇気を誰かへ渡す行為**として描く。

## 勝負どころ

### 1:57.0 Final Chorus
全編最大の開放点。

- 1:53.4〜1:57.0のG4で情報量を極端に落とす。
- 1:57.0はディゾルブではなく真のハードカット。
- S33で一気に明るさ・広がり・前進感を解放する。
- 序盤から最大の笑顔や最強の決め写真を出し切らない。

### 「だれかに わたせたなら」2箇所

- 1:07.2: G3。人物・人体なし。ひとつの小さな光が生まれる。「渡したい」という願い。
- 2:16.0: G5。人物・人体なし。ひとつの光が複数へ広がる。「すでに届いている」状態。

同じ表現をコピーせず、2回目は物語を進展させる。

## 本人素材の扱い

### 使う
- 公開・使用確認済みの本人写真
- 公開・使用確認済みの本人実写動画
- 通常編集によるカット、配置、パン、ズーム、クロスディゾルブ、色調整

### 使わない
- AIによる本人の顔の生成・置換・補正・加工
- AIによる本人写真のReference-to-Video化
- 本人に実際にはしていない動作を生成で付与すること
- AIリップシンク
- 生成塗り足しによる本人写真の拡張
- 配信画面録画 / SHOWROOMスクリーンショットをMV素材として使うこと

本人写真・動画のファイル本体はこのpublic repoへ置かない。

## AI生成映像の範囲

生成AIは、**本人・人物・人体が登場しない情景 / 象徴B-rollのみ**。

`STORYBOARD.md`で確定している6本以外を勝手に増やさない。

- G1 0:00.0 — 朝の光 / 逆光の粒子
- G2 0:41.2 — 太陽 / 光芒 / タイトル回収
- G3 1:07.2 — 闇の中に生まれる小さな光
- G4 1:53.4 — ほぼ暗闇 + 小さな光
- G5 2:16.0 — ひとつの光が複数へ広がる
- G6 2:34.2 — 朝日 / 余韻

G3を含め、手・顔・シルエットなど人体も出さない。
ひまわりは使わない。歌詞に無く、季節記号として強すぎるため、光・逆光・朝日で統一する。

## 写真の量

写真は **42カット**配置する。ただし42枚のユニーク写真が必須という意味ではない。

- 写真カット: 42
- ユニーク写真目安: 28〜32枚
- 再使用可。引き / クロップ / 横パン等で別カットとして見せる。
- S14 / S33 / S42の3枚は再利用しない専用Heroを優先する。

写真を多く使う目的は枚数自体ではなく、本人の活動・表情・自然体を豊かに見せること。

## 遊びのポイント

「トマトの えいようそ」は全編の感動トーンから少し外してよい。
真面目な感動映像を当て続けず、軽さ・可愛さ・意外性を入れる。

## 編集環境

CapCutは制作前提にしない。

- FFmpeg + Codex / Cursor / Claude Code等のローカル環境を本線にする。
- Canvaはタイトル、クレジット、サムネイル、必要な最終調整に任意利用する。
- 編集キットと本人素材はpublic fan-site repoへ置かず、local / privateで運用する。

## コスト方針

追加課金が必要な生成処理は原則禁止。

- 実行前に0円 / 加入プラン内 / Unlimited枠か確認する。
- 有料クレジット消費が必要なら実行せず停止して報告する。
- FFmpeg編集・検算・文書作業など0円のレーンを優先する。

## 長期公開への配慮

歌詞内の「にちだいの さんねんせい」のような年度で変化する情報は、音源の一部として扱う。
映像テロップや固定コピーで重ねて強調しすぎない。
