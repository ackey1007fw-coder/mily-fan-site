# SNS公開ゲート — Green Lane

この文書は、みりぃ（三橋莉子）のファン制作コンテンツを Instagram / TikTok / YouTube / X へ出すときの公開判定をそろえるための運用ルールです。

## 目的

- SHOWROOM由来の録画・録音データを外部SNSへ再投稿しない。
- 本人の魅力が伝わる歌唱・動画企画を止めず、最初から公開可能な素材で制作する。
- 「過去に投稿したことがある」「短尺」「非営利」「クレジット表記」だけを許諾根拠にしない。
- 判定が明確な素材だけを自動投稿候補へ送る。

## 3色ゲート

### GREEN — そのまま投稿候補

次の条件をすべて満たす素材。

1. **素材の入口がSHOWROOM録画・録音ではない。**
2. 映像・写真・音声について、ファン制作での公開利用が確認できる。
   - 依頼者が自ら制作した素材
   - 本人または権利者から公開利用を明示的に認められた素材
   - 各サービスの公式なRepost / Remix / Duet / Stitch等で、サービス上の共有機能として利用できる素材
3. 第三者の顔・私的情報・コメント・通知・位置情報などを含まない。
4. 音楽を含む場合、使用する音源と投稿先の条件を確認済み。
   - 本人のアカペラ / 弾き語り / 自作演奏を新規収録したもの
   - Instagram / TikTok / YouTube 等で投稿時にサービス側の公式音源を追加するもの
   - その他、原盤・楽曲の必要な許諾が確認できたもの
5. 投稿先別の権利条件を満たす。

GREEN は編集・カバー作成・投稿準備まで進めてよい。自動投稿を行う場合も、対象アカウント・重複・公開範囲を直前に再確認する。

### YELLOW — ネイティブ共有 / リンクのみ

素材そのものの再アップロード許諾は確認できないが、本人が公開した投稿を紹介できるもの。

例:
- 本人Xの投稿をRepost / Quote
- Instagramの公式共有機能でShare / Repost
- TikTokのRepost / Duet / Stitchが投稿側で許可されている場合
- 本人の公開動画へのリンク
- ファンサイトから本人の元投稿へアウトバウンド導線を置く

YELLOW は**ダウンロードして再アップロードしない**。元投稿への導線を優先する。

### RED — 外部公開しない

以下は外部SNSへの再投稿に使わない。

- SHOWROOM上の配信を録画・録音したデータ
- 上記録画から切り出した動画・音声
- SHOWROOM録画音声からボーカルだけを分離したもの
- 権利確認できないカラオケ伴奏・CD音源・配信音源を焼き込んだ動画
- 出典・権利・人物情報が未確認の素材
- 第三者の私的情報やコメントUI等を含む素材

SHOWROOM公式のカラオケ案内は、SHOWROOM上の配信を録画・録音し、そのデータをSNSや動画投稿サイトへ二次利用することを禁止している:
https://www.showroom-live.com/campaign/karaoke

## 歌唱コンテンツのGreen Lane

歌動画を増やしたい場合は、SHOWROOM録画から救済するのではなく、**SHOWROOM外で新規収録する**。

推奨フロー:

1. みりぃ本人をスマホ等で15〜30秒新規収録。
2. 収録時は以下のどちらかにする。
   - アカペラ / 本人の自作演奏
   - イヤホンでガイドを聴き、収録ファイルには本人の声だけを入れる
3. 9:16マスターを作る。顔加工・生成置換はしない。
4. Instagram / TikTok / YouTube では、必要に応じて投稿画面側の公式音源を追加する。
5. 音楽著作権の管理先・対象サービスの条件を曲ごとに確認する。
6. Xは別判定。JASRACの「利用許諾契約を締結しているUGCサービスの一覧」にXは掲載されていないため、著作権保護中のカバー曲をGREEN扱いしない。Xは静止画・短い告知・Instagram/TikTok/YouTubeへのリンクを基本とし、個別に権利根拠が確認できた場合だけ例外とする。

JASRACの許諾契約済みUGCサービス一覧（2026-08-21更新）:
https://www.jasrac.or.jp/information/topics/20/ugc.html

Instagram / TikTok / YouTube は上記一覧に掲載されている。ただし、これは**すべての原盤・映像・人物素材の再利用を許可するものではない**。第三者が制作した伴奏や市販音源の原盤権、本人素材の利用許諾等は別に確認する。

## 投稿前チェック

各候補について次を1行で残す。

- source: どこで作られた素材か
- owner/reuse: 誰が制作し、公開利用の根拠は何か
- music: アカペラ / 自作演奏 / platform-native / licensed / none
- platform: Instagram / TikTok / YouTube / X
- gate: GREEN / YELLOW / RED
- checkedAt: YYYY-MM-DD
- note: 例外・制約

### 例

```text
source: outside-showroom-new-recording
owner/reuse: performer-approved-for-fan-publication
music: platform-native
platform: instagram,tiktok,youtube
gate: GREEN
checkedAt: 2026-09-19
note: Xは別判定。外部音源を動画へ焼き込まない。
```

## 自動化ルール

- GREEN だけ編集・投稿キューへ送る。
- YELLOW は「リンク / native share」タスクへ送る。
- RED は非公開アーカイブに残し、公開キューへ送らない。
- 判定不能は GREEN に倒さず YELLOW または保留にする。
- 同じ素材でも投稿先ごとに gate が違う場合がある。
- 一度の判定を永続許可として流用しない。素材・曲・投稿先・利用方法が変われば再判定する。
